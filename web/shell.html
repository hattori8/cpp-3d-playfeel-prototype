astro_proto ─ アストロボット風 基本操作プロトタイプ

C++17 + raylib を WebAssembly にビルドしたもの。ネイティブ版と同じソースです。

読み込み中…

WebAssembly を展開しています。

操作（キーボード）

移動W A S D
カメラQ E / ← →（上下 ↑ ↓）
ジャンプSpace
ホバーSpace を押し続ける
パンチJ（地上）
レーザー空中で J を押し続ける
能力（ダッシュ）K を押し続ける（黄色いアイテムを拾うと使える）

操作（ゲームパッド）

移動 / カメラ左スティック / 右スティック
ジャンプ×（長押しでホバー）
パンチ / レーザー□
能力（ダッシュ）R2 を押し続ける
パッドはブラウザに認識させるため、接続後に一度ボタンを押してください。
開始後は Space・矢印・F5 などのブラウザ既定動作を止めています。

デバッグ / チューニング

F1状態表示
F2当たり判定の表示
F3パラメータエディタ
PgUp PgDn項目を選ぶ
- =値を増減（押しっぱなしで連続）
F6現在値をブラウザのコンソールに出力
R / F9復帰 / レベル作り直し

F3 → PgDn で項目を選び - = で数値をいじると、手触りがその場で変わります。 気に入った値は F6 でコンソール（F12 → Console）に出るので、そのまま params.txt に貼ってください。
