astro_proto ─ アストロボット風 基本操作プロトタイプ

C++17 + raylib を WebAssembly にビルドしたもの。ネイティブ版と同じソースです。

▶ レベルエディタを開く  ─ ブラウザだけでコースを編集して level.txt を書き出せます

level.txt をドロップして読み込む

デバッグ / チューニング

F1状態表示
F2当たり判定の表示
F3パラメータエディタ
PgUp PgDn項目を選ぶ
- =値を増減（押しっぱなしで連続）
F6現在値をブラウザのコンソールに出力
R / F9復帰 / レベル作り直し

レベルエディタ（F4）

選択 / 種類左クリック、[ ] で種類、Tab で次
移動←→↑↓ PgUp PgDn（Shift＝大きさ）
追加 / 複製 / 削除N / C / X
部分切替T（移動床のA・B、スライダーの制御点）
数値, . で項目、- = で増減
カメラ右ドラッグ回転 / ホイール / WASDQE

レベルエディタのページで編集したものは、 上のボタンでそのまま読み込めます（同じブラウザに保存されているため）。 キャンバスに level.txt をドロップしても構いません。ブラウザ版の保存は ダウンロードです。降りてきた level.txt をリポジトリ直下に置いてビルドし直すと、 公開版の既定レベルになります。

F3 → PgDn で項目を選び - = で数値をいじると、手触りがその場で変わります。 気に入った値は F6 でコンソール（F12 → Console）に出るので、そのまま params.txt に貼ってください。
