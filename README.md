# 3d-playfeel-prototype ─ 3D アクションの「手触り」を数値で詰めるための試作

**▶ ブラウザで遊ぶ（インストール不要・約 30 秒）: https://hattori8.github.io/cpp-3d-playfeel-prototype /**

MIT License（`LICENSE`）。依存は raylib 5.5（zlib License）と Jolt Physics 5.6（MIT License）のみで、外部アセットは一切使っていません。


## AI の利用について

本プロジェクトでは、実装・デバッグ・コードレビューの補助として AI コーディングツールを使用しています。

AI は実装を高速化し、より多くの案を試すためのツールとして利用しています。ゲームプレイの設計や最終的な技術判断は自分で行い、実際に触って比較しながら、移動・ジャンプ・カメラ・物理挙動などのパラメータを調整しています。

## レベルエディタ（F4）

ゲームを起動して **F4** で編集モードに入ります。世界が止まるので、移動床やゲートが
「作者が置いた位置」のまま触れます。

- 左クリックで選択 / `[` `]` で種類切替 / Tab で次の個体
- 矢印・PgUp/PgDn で移動（Ctrl=細かく、Shift=大きさ）、`T` で部分（A/B・制御点）切替
- `N` 追加、`C` 複製、`X` 削除、`B` 箱の種類、`G` スナップ、`P` 自機をここへ
- カメラ: 右ドラッグ回転 / ホイール寄り引き / WASDQE 移動
- **F6 で `level.txt` に保存**、F5 で読み直し、F7 でコンソールへ出力、F9 でコードのレベルに戻す

起動時に `level.txt` があればそれを読みます（無ければ `BuildLevel()` のコードのレベル）。
`level.txt` を消せばいつでもコードの状態に戻ります。形式はテキストなので手で編集しても構いません。
ブラウザ版はファイルを書き出せないので、F7 の出力をコピーして使ってください。


## ブラウザ版のビルドについて

`web/build_web.sh` は emsdk を想定していますが、Ubuntu なら `sudo apt install emscripten`
（3.1.6）でも通ります。古い emsdk 向けの差は CMakeLists.txt 側で吸収しています
（`TOTAL_STACK` / `STACK_SIZE` の出し分け、`MINIFY_HTML=0`、GLFW シムの補完）。


## ブラウザだけで使えるレベルエディタ

`tools/level_editor.html` をブラウザで開くだけで動きます（ビルド不要・three.js 同梱・オフライン可）。
`level.txt` を読み書きするので、ゲーム本体とデータを共有します。

1. 開く → 既定レベルが表示される（前回の編集はブラウザに自動保存されます）
2. クリックで選択、ドラッグで移動、右のパネルで数値を編集
3. 「level.txt を保存」→ 落ちてきた `level.txt` をリポジトリ直下に置く
4. `web/build_web.sh --publish` → `docs/index.html` が更新され、公開版に反映されます

`level.txt` を消せば、いつでも `BuildLevel()` のコードのレベルに戻ります。


## すぐ試す（ビルド不要・Windows）

`dist\astro_proto.exe` を、**リポジトリ直下から**実行してください（`level.txt` と `params.txt` を
そこから探すため）。エクスプローラでダブルクリックでも、直下に置いたままなら動きます。

- <kbd>F4</kbd> … レベルエディタ
- <kbd>F3</kbd> … パラメータエディタ（<kbd>-</kbd> <kbd>=</kbd> で数値を増減）
- <kbd>F1</kbd> … 状態表示

MinGW-w64 でクロスビルドした単体の exe です（追加の DLL は不要）。中身は同じソースなので、
自分でビルドし直せば置き換えられます。
